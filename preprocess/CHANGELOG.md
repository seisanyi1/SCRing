# 版本记录

首个清洁发布版。

### 模块

- 圆域提取
  - 绿色特征 / 灰度 / RGB 最大通道
  - 非固定半径、半高边缘、稳健圆拟合
  - 单圆 / 多圆、归一化 ROI、原始裁剪、掩膜、叠加图、极坐标
  - 运行记录、进度、取消、预览调参、逐图排除
  - 结果筛选、详情、逐图删除、重新运行
  - 自定义输出文件夹、CSV、HTML 报告
- 圆域切割
  - 基于提取结果的红域圆心和半径
  - 只保留圆域，圆外置黑
  - 自动重心与圆心偏差
  - 按圆心角分割整圆
  - 单扇区 PNG、扇形拼图、分割线图、CSV、ZIP
  - 图片多选 / 全选、批量切割
- 界面
  - 树状侧栏：圆域提取 / 圆域切割
  - 西文 Times New Roman，中文宋体
  - 表格文字居中
  - 本地服务，无需 Flask/FastAPI
